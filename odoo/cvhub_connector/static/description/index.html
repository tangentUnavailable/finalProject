CvHub Connector

Import positions and their aggregated results from a CvHub instance (per-inventory API token), browse them read-only, and — optionally — create positions in Odoo and export them back to CvHub.

Import

Menu CvHub → Import from CvHub: paste the base URL of the CvHub site and the API token generated on the position page (button “API token”), then click Import. Positions are stored with their attributes (title, type) and the aggregates computed by CvHub (avg/min/max for numeric attributes, most popular values for texts, yes/no counts for booleans, date ranges for periods).

Viewer

CvHub → Positions shows the list of imported positions; open one for the detailed view with per-attribute aggregates. “Refresh from CvHub” re-fetches fresh aggregates for a position.

Export-back (optional feature)

CvHub → Create & Export Position: create a position in Odoo and push it to CvHub through the same token (the position appears in CvHub immediately).
